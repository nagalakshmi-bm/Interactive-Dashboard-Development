# Interactive Dashboard Development

## Project Overview
This project presents an interactive sales dashboard using Python, Streamlit, Pandas, and Plotly.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit

## Project Features
- Data loading and inspection
- Data cleaning and preprocessing
- Sales and profit analysis
- Interactive dashboard
- Region, category, and segment filters
- Monthly sales trend
- Sales by category
- Profit by region
- Customer segment analysis
- Top 10 products by sales

## Key Performance Indicators
- Total Sales
- Total Profit
- Total Orders
- Average Sales

## How to Run
1. Install libraries:
   pip install -r requirements.txt

2. Run dashboard:
   py -m streamlit run dashboard/app.py

## Dataset
Superstore Sales Dataset.

## Conclusion
This project demonstrates how interactive dashboards help analyze sales performance and support data-driven decisions.
